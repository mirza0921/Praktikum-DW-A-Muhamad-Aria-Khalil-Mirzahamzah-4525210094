## Keterangan

Sebuah kampus sedang merancang wireframe awal untuk Dashboard Portal Perpustakaan Umum. Halaman ini ditujukan untuk membantu mahasiswa melihat ringkasan informasi buku yang dimiliki secara cepat. Struktur tata letak (layout) terdiri dari elemen-elemen berikut:

Header (<header>): Memuat placeholder logo perpustakaan di sebelah kiri dan nama/profil user di sebelah kanan.
Navbar (<nav>): Berada di bawah header, berisi menu navigasi horizontal (Beranda, Daftar Buku, Peminjaman, Layanan, Kontak).
Layout Utama (<main>): Dibagi menjadi dua area menggunakan Flexbox atau CSS Grid:
Sidebar (<aside>): Berada di sisi kiri dengan daftar menu navigasi vertikal (Beranda, Daftar Buku, Peminjaman, Layanan, Kontak).
Area Konten Utama (<section class="content">): Berada di sisi kanan yang menampung kartu ringkasan (Card Grid) dan jadwal perkuliahan.
Footer (<footer>): Berisi informasi kontak universitas dan hak cipta.
Pilih salah satu antara navbar atau sidebar.
